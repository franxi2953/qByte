# qByte Data Analysis (Offline, Phaser UI)

This folder contains an offline web app with a Phaser-based interface to analyze `Processed Fluo` CSV files.

## Main Features

- Offline operation with local libraries in `vendor/`:
  - `phaser.min.js`
  - `chart.umd.min.js`
  - `papaparse.min.js`
- Phaser loading scene + main scene
- Foldable side panels (left/right)
- Tabs:
  - `Processed Fluo`: only the 8 fluorescence tubes
  - `Melting`: `-dF/dT` computed from fluorescence derivative over temperature derivative
- Sample editor (left panel):
  - Per-tube sample name
  - Per-tube color
  - Palette presets (`macOS`, `Viridis`, `Plasma`, `Ocean`)
- Melting controls (right panel):
  - Temperature channel selector
  - Analysis range (%)
  - Smoothing window
- CSV export for active tab

## Expected CSV Format

1. First column: `Time`
2. Middle columns: fluorescence channels (first 8 are used)
3. Last 5 columns: temperature channels (including target temperature)

This is compatible with the `Processed Fluo` export generated by the qByte UI.

## Run

Open `index.html` in a browser.
